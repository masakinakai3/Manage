# Terminal & Browser Verification Rules

実装完了後、ユーザーに報告する前に必ず以下の自己検証（Self-Verification）プロセスを実行すること。

## ターミナルでの検証
- 修正完了後、必ずターミナルで lint コマンドや型チェックを実行する。
- 静的解析エラーが出た場合は、自律的にエラーログを読み込み、コードを修正すること。

## ブラウザでの検証（UIタスクの場合）
- UIコンポーネントやフロントエンドの修正を行った場合は、ターミナルで開発サーバーを立ち上げる。
- 統合ブラウザを開き、実装した画面のレンダリングや挙動が正常か確認する。
- ブラウザのコンソールにエラーが出ていないか確認し、あれば自己修正を試みる。
