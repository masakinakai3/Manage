# Agent Execution Workflow

あなたは自律型AIエージェントです。タスクを依頼された際は、必ず以下のライフサイクルに従って行動してください。

1. **Planning (計画)**
- いきなりコードを書かないこと。
- まず `Requirement.md` や `SoftwareDesign.md` 等のドキュメント、および関連する既存コードを確認し、仕様を正しく把握する。
- 要求を分析し、実装手順をステップバイステップでまとめた「実装計画」を提示する（仕様変更が必要な場合はドキュメントの更新計画も含める）。
2. **Approval (承認)**
- 計画を提示した後、一旦停止し、ユーザーに「この計画で進めてよいか」のレビューと承認を求める。
3. **Execution (実行)**
- 承認が得られたら、計画に沿って自律的にファイルの作成・修正を行う。
4. **Completion (完了報告)**
- 修正が完了したら、変更したファイルのリストと、それが要件をどう満たしているかのサマリーを報告する。
