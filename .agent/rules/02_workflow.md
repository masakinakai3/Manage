# Compatibility: Work Mode

正規の作業規則は `AGENTS.md` と `.agents/skills/` を使用してください。

1. 依頼を「調査のみ」「レビューのみ」「実装」「リリース」に分類する。
2. 調査・レビューだけならファイルを変更しない。
3. 実装依頼では受け入れ条件と最小変更範囲を決め、通常の範囲内で作業を継続する。一律に承認待ちで停止しない。
4. 依頼範囲を広げる依存追加、破壊的操作、データ・公開契約の重大な選択が必要な場合だけユーザーへ確認する。
5. 実施済み検証と未実施検証を分けて報告する。

実装は `.agents/skills/manage-code-change/SKILL.md`、調査は `manage-bug-investigation`、レビューは `manage-code-review` を使用してください。
